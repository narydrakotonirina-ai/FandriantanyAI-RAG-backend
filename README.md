# FandriantanyAI-RAG-backend
FandriantanyAI-RAG-backend est une API FastAPI implémentant un pipeline RAG (Retrieval-Augmented Generation) pour l’assistance juridique foncière à Madagascar.  Le système combine recherche vectorielle (Supabase + pgvector) et génération de réponses structurées via Groq (Qwen).
